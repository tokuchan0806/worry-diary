# 心配事日記（Worry Diary）

> **「心配事のほとんどは実際には起こらないか、起こっても大したことはない」**  
> 頭の中の心配事を書き出して、あとから結末を記録・振り返ることで「思ったより大丈夫だった」を実感するためのPWAアプリです。感謝の言葉や日替わりのプライミングワードも記録できます。

---

## ✨ 主な機能

1. **💭 心配事の記録と結末の振り返り**
   - ToDoリストのように気になった心配事と登録日を書き出せます。
   - 結果がわかったら、プルダウンから結末を選んで「終了」にできます：
     - 🌿 実際に起こらなかった（取り越し苦労だった）
     - 🌤️ 起こったが、大したことはなかった
     - ✨ 起こったが、うまく対応できた
     - 🌧️ 予想通り大変だった（対応に苦労した）
   - 「ひとこと振り返りメモ」も残せます。

2. **📊 安心統計（2つの視点で見える化）**
   - 終了した心配事のうち **「起こらなかった割合（％）」** と **「起こったけど大したことない／うまく対応できた割合（％）」** をそれぞれ集計して表示します。

3. **🌸 感謝の言葉の記録**
   - トップ画面のメニューから「心配事」と「感謝の言葉」を切り替えられます。
   - 他人への感謝や、自分の環境・日常の小さなありがとうを記録できます。

4. **📅 カレンダー表示**
   - 心配事や感謝を**登録した日**にカラー別のドットと件数が表示され、日付をタップしてその日の記録を振り返れます。

5. **✨ 日替わりプライミングワード**
   - 起動時やヘッダー下に、心を整える言葉（標準30種類）が日替わりで表示されます。
   - 「❤️ いいね」ボタンや、自分だけの言葉を追加・管理する機能もあります。

6. **🔍 種別・年・月での絞り込み**
   - リスト画面で「すべて／心配事／感謝」と「年／月」を組み合わせて記録を絞り込めます。

7. **💾 バックアップ（JSON書き出し・読み込み）**
   - サーバー不要で端末内（`localStorage`）にのみ保存されるためプライバシーも安心です。機種変更時用にJSONファイルでの書き出し・復元に対応しています。

---

## 📱 Androidスマホへのインストール方法（PWA）

1. Androidの **Google Chrome** で公開URL（例：`https://tokuchan0806.github.io/worry-diary/`）を開きます。
2. Chrome右上のメニュー **「⋮」** から **「アプリをインストール」**（または **「ホーム画面に追加」**）をタップします。
3. ホーム画面に追加されたアイコンから、通常のアプリのように全画面＆オフラインで起動できます。

---

## 📁 ファイル構成

- `index.html` : アプリの画面構造（CSP設定済み）
- `styles.css` : モバイル向けのレスポンシブデザイン
- `app.js` : アプリケーションロジック・ローカル保存・描画処理
- `manifest.json` : PWAインストール用マニフェスト
- `sw.js` : オフライン動作用 Service Worker
- `icon.svg` : アプリアイコン

---

## 🔒 プライバシーとセキュリティ

- 記録したデータはすべてブラウザ内の `localStorage` に保存され、外部サーバーへ送信されることはありません。
- ユーザー入力の描画はすべて `document.createElement()` と `textContent` を用いてXSS対策を行っています。
